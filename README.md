# Révisions CQP IF

Site de révision en français : 5 cours corrigés, 14 thèmes et 210 questions.

Chaque questionnaire comporte 10 questions. Une bonne réponse rapporte 1 point.
Le mode général mélange les 5 cours (2 questions par cours).

## Résultats

Les 60 derniers questionnaires terminés et leurs corrigés sont conservés localement
avec localStorage, dans le navigateur utilisé, y compris après fermeture du site.
Les résultats ne sont pas envoyés à GitHub et ne sont pas synchronisés entre appareils.
Effacer les données du site supprime cet historique. En navigation privée, sa durée est limitée.

## Hébergement

Fichiers statiques autonomes, sans dépendance externe ni étape de compilation.
GitHub Pages : Settings > Pages > Deploy from a branch > main > / (root) > Save.

Les cours sont consultables sur le site, sans bouton de téléchargement PDF ni d’impression.
Les commandes propres au navigateur restent disponibles.
Les questionnaires servent à réviser et ne constituent pas une banque officielle d’examen.
Les références scientifiques et réglementaires sont indiquées dans les cours.
